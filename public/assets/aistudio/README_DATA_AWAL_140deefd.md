# Data Awal Absensi Sekolah

Sekolah: MI Miftahul Ulum Sumberwuluh

## Isi paket
- `DATA_AWAL_GURU.csv` dan `.json`: 7 data guru sesuai daftar dari pengguna.
- `DEMO_DATA_SISWA.csv` dan `.json`: 24 data siswa sintetis untuk uji coba, tersebar pada kelas 1A–6B.

## Catatan penting
1. Data guru dimasukkan sesuai ejaan dan NIP yang diberikan.
2. Data siswa seluruhnya fiktif dan hanya untuk demo/pengujian. Ganti dengan data resmi sebelum produksi.
3. NIP dan NIS harus diperlakukan sebagai teks/string agar angka nol di depan tidak hilang.
4. File ini tidak berisi username atau password. Buat akun dan kredensial melalui alur administrasi aplikasi yang aman.
5. Nama kelas demo (1A, 1B, dst.) dapat disesuaikan dengan struktur kelas MI yang sebenarnya.
6. Kepala Sekolah pada data guru adalah IMAM MUSTHOFA; jabatan sesuai data yang diberikan.
